# 🌏 customer-behavior-analysis-project
## 👁 Project Overview
### 📌**Objective:** identify revenue drivers and customer purchase behavior by analyzing 2 years of historical sales data.  

  
This project is a comprehensive end-to-end analytics project using Myntra's customer-base data, mirroring the real-world responsibilities of professional analysts in the modern-world business environments. The project covers all the critical techniques and tools used by integrating Python, SQL, and Power BI for analysing data from data preparation and modeling, feature-engineering to insight generation, visualization and reporting that allows stakeholders to make data-driven decisions.

## 🛠 Tools & Techniques
**--> _Python/Pandas_ :** Data preparation & modeling, EDA, Feature Engineering.  
**--> _SQL_ :** Data Analysis via queries to extract insights on customer segments, loyalty, and purchase drivers.  
**--> _PowerBI_ :** Built an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.

## 💼 Business Impact & Key Insights
1. The **Male demographic** of customers generate more than **2X** the revenue as compared to the female's but also has twice the number of customers. **Meaning the business is catered more towards the male demographic**.
  
2. Customers on average are willing to spend **8% more on Express Shipping**.
  
3. Non-subscribed customer **make up 73% of the entire customer base**. There maybe some issue with the subscription model non-incentivizing people to subscribe.
  
4. The clothing product category is by far the most revenue generating **(3% more than all other categories combined)** even with the highest percentage of discounts applied.

## 🛠️ Core Competencies Demonstrated

**Data Pipeline Engineering (ETL):** Built robust Python scripts (pandas, numpy) to extract, clean, and standardize large datasets.

**Relational Database Design:** Engineered a normalized SQL database, writing complex queries (CTEs, Window Functions, Multi-table Joins) to extract targeted analytical datasets.

**Advanced Data Visualization:** Designed an intuitive, user-centric Power BI dashboard focused on UI/UX best practices, DAX optimization, and actionable KPI tracking.

**Data Storytelling:** Translated complex technical findings into clear, non-technical business recommendations.

## 🏗️ Technical Architecture & Workflow

**Data Ingestion:** Extracted/loaded raw data from CSV into a Python environment.

**Data Preprocessing (Python):** Handled missing values, standardized data types, and engineered new features for deeper analysis.

**Data Storage (SQL):** Loaded the cleansed data into a MySQL database, structuring it into a Star Schema.

**Data Modeling (Power BI):** Established relationships between fact and dimension tables.

**Dashboard Development:** Created DAX measures for dynamic time-intelligence and KPI reporting.
