# 🌏 customer-behavior-analysis-project
## 👁 Project Overview
This project is a comprehensive end-to-end analytics project using Myntra's customer-base data, mirroring the real-world responsibilities of professional analysts in the modern-world business environments. The project covers all the critical techniques and tools used by professionals for analysing data from data preparation and modeling, feature-engineering to insight generation, visualization, and reporting.

## 🛠 Tools & Techniques
**--> _Python/Pandas_ :** Data preparation & modeling, EDA, Feature Engineering.  
**--> _SQL_ :** Data Analysis via queries to extract insights on customer segments, loyalty, and purchase drivers.  
**--> _PowerBI_ :** Built an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.
